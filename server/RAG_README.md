# 机器学习 Demo

## 运行

本演示固定为机器学习课程，资料由后台自动使用。界面不再要求用户选择或绑定资料。

- 后端：在 server 目录运行 npm start。
- 前端：在 frontend 目录运行 npm run dev。
- 点击“创建机器学习知识树”，选择节点学习；无需配置资料归属。
- 请新建一棵知识树查看新的课程结构，已有树的节点和手工笔记不会被自动改写。

## 节点结构

mlCurriculum.js 定义课程骨架和具体学习目标。一级模块为：模型评估与选择、线性回归、逻辑回归与Softmax回归、k近邻分类、朴素贝叶斯分类、支持向量机、决策树与集成学习、神经网络与梯度优化、聚类与高斯混合模型、主成分分析。

每个模块包含4–5个具体学习单元。例如线性回归下是：线性预测与最小二乘目标、正规方程与可逆条件、梯度下降求解线性回归、岭回归与Lasso正则化、高斯噪声与最大似然解释。每个单元写明学习任务、适用条件与边界。

课程骨架是明确配置的教学规划，不伪称是模型实时推导或所有教材共同认可的唯一目录。标准模块和聚焦学习单元无需模型自由生成目录，减少笼统节点和等待；细节在笔记中讲解。遇到不在课程表中的自定义节点，才检索机器学习教材，并结合当前摘要、祖先链、兄弟范围交给模型规划，拒绝“基本概念、算法原理、实际应用”等通用栏目。

原先一级最多6个节点的约束提高到10个，避免将算法家族硬挤成几个空泛大类。课程节点仍保留单次展开最多5个子节点的约束。

旧的非机器学习知识树不出现在此 demo 列表中，但数据库原记录没有删除。手动资料切换的前端和后端接口已移除；此前数据库若已有 dataset_id 等列，不再使用，不必清空数据库。

## 后台资料

- 6个 D2L 中文结构化章节：线性回归、Softmax、欠拟合与过拟合、权重衰减、反向传播、随机梯度下降。
- MML 英文教材第8–12章：模型与数据、回归、PCA、GMM、SVM。
- ISLP 为可选下载项，目前官网下载超时，当前索引没有包含该书。

资料目录记录在 datasets/machine-learning.json，包含书名、版本、语言、章节和官方来源；索引记录实际文件SHA-256。当前483个片段。

课程表比当前资料覆盖更广：k近邻、朴素贝叶斯、决策树与集成等模块尚缺对应完整教材章节。不能把课程表当成RAG覆盖证明；笔记只能在摘录直接支持的论断后引用，资料不足时应明确说明。这是下一批资料补齐的重点。

初次拉取项目可运行：

    npm run rag:fetch -- machine-learning
    npm run rag:index

本地已下载资料和索引可直接使用。资料或配置变化后重新建索引；原 NLP 课件、索引与兼容检索代码已移除。

Markdown 按标题和段落切分，保留完整公式及代码块；PDF 使用书签路径和PDF页码，文字和公式仍可能有提取缺失。小片段命中后补充同一小节邻近段落，上下文有字符预算并按小节去重。

## 检索与缓存

默认关键词检索，包含中英文术语别名。无RAG、无别名关键词、语义和混合模式保留用于后台评测，不出现在用户资料选择流程中。

语义模型可设置 RAG_EMBEDDING_MODEL=embedding-3，复用现有智谱配置，再运行 npm run rag:embed -- machine-learning。当前已构建向量，但默认不切换到语义模式；小型开发集没有显示更高Hit@3，且有接口耗时。

笔记缓存包含课程版本、提示词哈希、子节点结构及检索版本。修改课程或提示词后不会继续复用旧笔记缓存；已有子节点不自动删除重建，以保留编辑记录。

有资料却既没有引用也没有资料不足说明时会触发重试。引用编号合法性不等于结论正确，仍需检查引用支持范围和数学计算。

## 验证

    npm run test:rag
    npm run rag:eval
    npm run rag:eval -- --generate --ids=softmax,pca --modes=none,baseline,keyword,hybrid

test:rag 验证标准课程结构、叶子终止、教材语境注入、自动检索、非机器学习主题拒绝、NLP旧树隐藏、建树与展开的数据库流程以及引用检查。测试用临时数据库，不修改本地学习记录。

evaluation 下保存早期检索、生成与失败案例记录。REVIEW.md 对其中的数值错误和引用不足有明确记录，不能据此宣称笔记正确率100%。历史对照中的手动绑定机制已被此版单课程demo取代。


## 导入文件的持续资料来源

通过文件导入创建的知识树会自动保存提取后的原文、正文片段、章节或 PDF 页码，以及节点对应的片段编号。短文件直接规划；长文件分批提取要点后汇总，覆盖全文。后续展开、讲解计划、补检索和笔记生成均使用该树关联的文件；导入机器学习文件时不会套用内置课程骨架或混用教材索引。笔记引用自动显示文件名及章节或 PDF 页码，手工编辑不会改写原文。

资料存储在 SQLite 的 imported_documents、imported_document_summaries 和 node_document_sources 表，后端启动时自动建表；删除知识树时一起清理。旧版本导入的树未保存原文，需要重新导入原文件才能使用这一流程。普通主题建树与机器学习教材 RAG 保持原有路由。

新增回归测试已纳入 `npm run test:rag`，包括全文后半段覆盖、PDF 分页提取、文件来源隔离、节点展开、流式笔记、人工编辑和删除清理；模型响应在测试中使用模拟结果。

长文件归纳只要求纯文本要点，不生成知识树 JSON，也不要求逐个列全片段编号。程序逐批送入全文，并保存每批摘要与输入片段的关联；该关联表示处理范围，不等同于引用支持。最终建树才生成结构化节点，程序按节点名称和摘要在原文中匹配相关片段，匹配不到时不随意填充来源。模型如返回来源编号，仍检查其属于当前文件。每批最多两次尝试，无递归拆批；单次导入最多64批、3轮压缩，失败或超限会明确结束。

## 错误提示与调试信息

用户页面只显示操作结果和可执行建议，例如“资料导入失败，请稍后重试”；不显示模型解析位置、字段名、重试阶段、数据库错误或诊断文件路径。文件格式、大小及正文不足等输入问题仍提示用户处理。后台终端保留具体失败原因，结构化模型响应失败时可在 tmp/ai-output-diagnostics 查看诊断。JSON 接口与流式笔记接口共用 publicErrors.js 的错误边界。

结构化结果仅允许去除首尾空白和完整的外层 Markdown 代码块；不再猜补括号、修改反斜杠或静默修复损坏内容。正文归纳使用纯文本，最终节点仍校验必填字段、层级和来源。

## 笔记计划与知识树范围

讲解要点通过 childIds 关联已保存子节点，允许改写标题、合并相关知识和调整顺序；必要背景要点可以不关联子节点。遗漏的子节点由程序依据原有摘要补入计划，不使用标题逐字相同或顺序一致作为成功条件。结构或来源校验连续两次失败时，丢弃无效计划，用已有节点组织讲解并继续文件内补检索和正文生成；不继承无效来源，不把网络和模型服务异常当作有效计划。计划版本更新会使自动生成笔记缓存重新校验，手工笔记仍受保护。
